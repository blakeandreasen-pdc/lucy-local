Try a command

Send any command to the robot to see what it does, without touching a profile. rx is the app's command channel (a command name, its data and a key); dp is the smart-speaker channel (a data point id and a value). Start from one of the profile's actions or type your own. The Max often answers 1-2 minutes later; replies appear below as they arrive.

Robot profile

A profile says which command each control sends, because models differ: on a Trifo Max reverse is ANGLE:10, on a Lucy ANGLE:8. Put {value} where a number or choice goes (volume, suction, language). Test sends that one command now.
