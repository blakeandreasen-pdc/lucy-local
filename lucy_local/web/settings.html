Wi-Fi setup

Puts the robot on Wi-Fi without the Trifo app: it reads this QR code with its camera. The code is made in this browser; the password isn't sent to the server or saved. Open this page on your phone so you can hold the code up to the robot.

Advanced

The robot uses the region to pick which Trifo server names to look up. Keep the one it used before (lucy-local's log shows it on connect, e.g. "eu"); the DNS rules cover all of them anyway.

  1. Put the robot in network-configuration mode (on the Lucy, hold the recharge button for 5 s until it says so; check your model's manual).
  2. Tap the code to show it full screen, at full brightness.
  3. Start about 1 m from the robot's camera and move slowly closer until it announces success.
  4. It appears here as online within a minute or two, provided your DNS points the Trifo names at this server.
